# KHI openbsd-ports

Assuming you have an OpenBSD build system setup for building and maintaing ports as per

- https://www.openbsd.org/faq/ports/ports.html
- https://www.openbsd.org/faq/ports/guide.html

## Using them

Clone this repository into /usr/ports/mystuff on your build system.

You can then build and maintain the ports
